# Crazy Animals

A 3D puzzle game: animals appear on four sides of the game field, and the player must move them into the center in the correct order to assemble them into a single formation while avoiding collisions.

Built in 2024 with Unity using **DragonECS** — during its peak and growing popularity within the Russian-speaking gamedev community.

Developed for the **Yandex Games** platform, but was removed from the general game catalog due to low ratings.

## Features
- Simple one-tap controls
- Multiple levels of increasing difficulty
- Collectible animal characters to unlock
- Record tracking and daily rewards

## Tech Stack
- Unity
- DragonECS
- PrimeTween
